Политика приватности

Действует для расширения Speacher и веб-версии. Обновлено 15 ноября 2026.

Коротко

У Speacher нет своего сервера. Аудио уходит только в Groq для распознавания, ключ и история хранятся в вашем браузере. Мы не собираем аналитику, не ведём аккаунты и не передаём данные третьим лицам.

Какие данные обрабатываются

  • Аудио с микрофона. Записывается только пока диктовка активна (хоткей или кнопка). Отправляется напрямую в Groq API и не сохраняется на промежуточном сервере — его просто нет.
  • Распознанный текст. Обрабатывается моделью Groq для чистки и вставляется в активное поле страницы.
  • Ключ Groq API. Вводится вами в настройках и хранится локально в chrome.storage.local (расширение) или localStorage (веб-версия). Передаётся только в Groq как заголовок авторизации.
  • История диктовок, личный словарь, настройки. Только на вашем устройстве. Историю можно выключить или очистить в любой момент.

Что расширение НЕ делает

  • Не читает содержимое страниц. Content script рисует только индикатор записи.
  • Не делает скриншотов и не читает текст вокруг курсора.
  • Не отправляет данные никуда, кроме https://api.groq.com.
  • Не содержит аналитики, трекеров и рекламы.
  • Не требует регистрации и не создаёт аккаунт.

Разрешения и зачем они нужны

  • storage — хранить настройки, ключ, словарь и историю локально.
  • scripting, activeTab — вставить готовый текст в поле активной вкладки.
  • offscreen — записывать аудио, пока попап расширения закрыт.
  • commands — глобальная комбинация клавиш для старта диктовки.
  • host_permissions: api.groq.com — отправлять запросы распознавания.

Третьи стороны

Единственный получатель данных — Groq (политика приватности Groq). Условия хранения аудио на стороне Groq определяются их политикой и вашим тарифом.

Ваши действия

  • Удалить историю — в настройках расширения, кнопка «Очистить историю».
  • Полностью удалить данные — удалить расширение или очистить данные сайта.
  • Отозвать ключ — в консоли Groq, раздел API Keys.

Дети

Сервис не предназначен для детей младше 13 лет и не собирает их данные осознанно.

Изменения

При существенных изменениях обновляется дата в начале страницы, а в расширении — версия. История правок доступна в репозитории проекта.

Вопросы и сообщения об ошибках — через issues в репозитории проекта.
