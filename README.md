# Speacher

AI-диктовка: говорите как думаете — получаете готовый текст. Убирает «э-э» и оговорки, восстанавливает самокоррекции, ставит пунктуацию и абзацы, подстраивается под стиль.

**Движок:** Whisper Large v3 через Groq API (`whisper-large-v3-turbo` по умолчанию, `whisper-large-v3` — точный режим) + LLM-чистка (`openai/gpt-oss-20b`).
**Ключ:** свой (BYOK), вводится в настройках. Сервера нет вообще.

Два продукта из одного репозитория:

| Продукт | Что умеет | Где живёт |
|---|---|---|
| **Расширение Chrome** | глобальный хоткей, диктовка в любое поле любой вкладки, пилюля поверх страницы | `dist-extension/` |
| **Веб-версия** | то же ядро без установки, текст в буфер и в поле на странице | `dist/` (GitHub Pages) |

---

## Быстрый старт: расширение

```bash
npm install
npm run build:ext        # → dist-extension/
```

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. «Загрузить распакованное расширение» → выберите `dist-extension/`
4. Откроется страница настроек — вставьте ключ Groq с [console.groq.com/keys](https://console.groq.com/keys)
5. Назначьте удобную комбинацию в `chrome://extensions/shortcuts` (по умолчанию `Ctrl+Shift+Space`)

Или скачайте готовый `speacher-extension.zip` со страницы сайта / из релиза и распакуйте.

**Как пользоваться:** нажмите хоткей → говорите → ещё раз хоткей (или `Enter`) → текст вставляется в активное поле. Внизу страницы видна пилюля с волной и таймером.

## Быстрый старт: веб-версия

```bash
npm install
npm run dev              # http://localhost:5173
```

Ключ вводится в «Настройки» и хранится в `localStorage`. Деплой на GitHub Pages — автоматический через `.github/workflows/pages.yml` при пуше в `main`.

## Структура

```
shared/          общее ядро без DOM и chrome.* — одинаково для сайта и расширения
  prompts.ts       подсказка для Whisper (224 токена) и системный промпт чистки, 4 стиля
  groq-client.ts   клиент Groq: транскрипция, чистка, проверка ключа, разбор ошибок
  pipeline.ts      один проход: аудио → ASR → чистка → текст с замерами
  settings.ts      типы настроек и истории, дефолты, санитайзер
ext/             расширение Manifest V3
  manifest.json    права: storage, scripting, activeTab, offscreen, commands
  src/background.ts  команды, состояние, вставка текста, история
  src/offscreen.ts   запись и запросы, переживающие закрытие попапа
  src/capture.ts     MediaRecorder + RMS для волны
  src/content.ts     пилюля поверх страницы (ничего не читает со страницы)
  src/popup.tsx      быстрое окно: старт/стоп, результат, копирование
  src/options.tsx    ключ, модели, язык, стиль, словарь, история, приватность
  src/store.ts       chrome.storage.local
src/             веб-версия (React)
server/          необязательный режим self-host: тот же конвейер через Express
tests/           Vitest: конвейер и клиент Groq на моках
scripts/         проверки: расширение и API
```

## Почему две обёртки, а не одна

Ядро (`shared/`) не знает ни про DOM, ни про `chrome.*`. Расширение добавляет к нему права и вставку в страницы, веб-версия — интерфейс на React. Поэтому «работает в браузере» и «работает в любом приложении» — это один код диктовки и две тонкие обвязки, а не два продукта.

## Конфигурация

| Переменная | Где нужна | Назначение |
|---|---|---|
| `BASE_PATH` | сборка сайта | подпуть для Pages (`/Speacher/`) |
| `GROQ_API_KEY` | только для `npm start` (self-host) | ключ на сервере |
| `API_PORT` | self-host | порт API |
| `ASR_MODEL`, `ASR_MODEL_ACCURATE`, `LLM_MODEL` | self-host | выбор моделей |
| `MAX_UPLOAD_MB` | self-host | лимит аудио |

Для расширения и веб-версии переменные окружения **не нужны** — ключ вводится в интерфейсе.

## Проверки

```bash
npm run typecheck        # tsc: 0 ошибок
npm run test             # 12 тестов: конвейер, откаты, обработка ошибок
npm run build            # веб-версия
npm run build:ext        # расширение
node scripts/check-extension.mjs   # манифест, файлы, CSP, отсутствие ключей в бандле
bash scripts/smoke.sh    # 15 проверок API на моке Groq
```

Что именно покрыто:

- **Конвейер** (`tests/pipeline.test.ts`): успешный проход, режим accurate, выключенная чистка, отбраковка тишины по `no_speech_prob`, пустой ASR, откат при «модель дописала», откат при падении LLM, `429` с `retry-after`, отсутствие ключа без сетевого запроса.
- **Расширение** (`scripts/check-extension.mjs`): MV3, наличие всех файлов из манифеста, минимальные права, `host_permissions` на Groq, `content.js` без `import`, отсутствие inline-скриптов (CSP), отсутствие `gsk_…` в бандле.

**Не проверено и требует вашей ручной проверки:**

- реальный вызов Groq с настоящим ключом (в окружении разработки ключа нет);
- живая запись с микрофона (в песочнице нет аудиоустройства);
- вставка текста в конкретные сайты — Gmail, Google Docs, Notion, редакторы на ProseMirror. Это самая непредсказуемая часть: где-то работает `insertText`, где-то нужен обходной путь;
- установка расширения в Chrome — манифест проверен статически, но живую загрузку в браузер нужно сделать вам.

## Права расширения и приватность

`storage` — настройки и история локально; `activeTab` + `scripting` — вставить текст в активную вкладку; `offscreen` — запись при закрытом попапе; `commands` — глобальный хоткей. Content script **ничего не читает со страницы**, только рисует индикатор.

Аудио уходит только в `api.groq.com`. Своего сервера у расширения нет. Политика приватности — `public/privacy.html`, публикуется вместе с сайтом: `/privacy.html`.

## Ограничения

- Groq не поддерживает потоковое распознавание: текст появляется после конца записи, а не по словам во время речи.
- Минимум 10 секунд тарификации за запрос у Groq — очень короткие фразы невыгодны.
- Free tier Groq: 20 запросов/мин, 7 200 аудиосекунд/час, 28 800/день на организацию. Для личного использования с запасом, для публичного сервиса с общим ключом — нет. Поэтому ключ у каждого свой.
- Вставка невозможна на `chrome://` страницах и в Chrome Web Store — там текст остаётся в истории.
- Firefox не поддерживается (нужен отдельный манифест).
