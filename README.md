# Speacher

AI-диктовка: говорите как думаете — получаете готовый текст. Убирает «э-э» и оговорки, восстанавливает самокоррекции, ставит пунктуацию и абзацы, подстраивается под стиль.

**Движок:** Whisper Large v3 (Groq API, `whisper-large-v3-turbo` по умолчанию, `whisper-large-v3` как точный режим) + LLM-чистка (`openai/gpt-oss-20b`).
**Дизайн:** по мотивам Wispr Flow — тёмная пилюля, волны громкости, кремовый фон, крупная серифная типографика.

## Быстрый старт

```bash
npm install
cp .env.example .env      # вставьте GROQ_API_KEY с https://console.groq.com/keys
npm run dev               # http://localhost:5173
```

Без ключа приложение всё равно запускается: интерфейс работает, транскрипция отвечает понятной ошибкой `503 no_key`.

Продакшен-сборка и один процесс на всё:

```bash
npm run build
npm start                 # API + раздача dist на http://localhost:8787
```

## Как пользоваться

1. `Ctrl/Cmd + Shift + Space` (или кнопка в пилюле) — начать запись.
2. Говорите.
3. `Enter` — завершить, `Esc` — отменить.
4. Текст появляется ниже: кнопка «Копировать», «Вставить» в последнее поле на странице, переключение стиля, сравнение с дословной расшифровкой.

## Что уже работает (v0.1)

- Запись с микрофона, живая волна громкости, таймер, отмена.
- Распознавание через Groq Whisper (turbo / large-v3), автоопределение языка или явный ru/en.
- LLM-чистка: филлеры, повторы, самокоррекции, пунктуация, абзацы. Стили: обычный текст, сообщение, письмо, код.
- Защита от «модель дописала за пользователя»: при подозрительном ответе возвращается дословный текст с пометкой.
- Личный словарь → и в подсказку Whisper (224 токена), и в промпт чистки.
- Локальная история с поиском, копированием и удалением; сохранение можно выключить.
- Понятные ошибки: нет ключа, лимит Groq (с `retry-after`), пустая запись, тишина (`no_speech_prob`), слишком большой файл.
- Аудио не сохраняется на сервере: буфер уходит в Groq и забывается.

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `GROQ_API_KEY` | — | ключ Groq |
| `API_PORT` | `8787` | порт API |
| `ASR_MODEL` | `whisper-large-v3-turbo` | быстрая модель |
| `ASR_MODEL_ACCURATE` | `whisper-large-v3` | точная модель |
| `LLM_MODEL` | `openai/gpt-oss-20b` | чистка текста |
| `MAX_UPLOAD_MB` | `25` | лимит аудио (у Groq free tier — 25 МБ) |
| `GROQ_BASE_URL` | `https://api.groq.com/openai/v1` | для прокси/мока |

## Проверки

```bash
npm run typecheck   # tsc, 0 ошибок
npm run build       # сборка фронтенда
bash scripts/smoke.sh   # 15 проверок API на моке Groq, без ключа и без сети
```

`scripts/smoke.sh` поднимает мок Groq (`server/mock-groq.ts`) и прогоняет: health, успешную транскрипцию, пустое аудио, слишком короткую запись, чистку с филлерами и самокоррекцией, пустой текст, ответ `429` с `retry-after`, падение LLM с откатом на сырой текст, запрос без ключа.

**Что не проверено:** реальный вызов Groq с настоящим ключом и реальный звук с микрофона — в окружении разработки нет ключа и нет аудиоустройства. Контракты с Groq проверены по официальной документации и на моке.

## Ограничения v0.1

- Только браузер: диктовка работает, пока вкладка Speacher активна. Глобального хоткея поверх других приложений нет — это этап 6 (`PLAN.md`), обёртка Tauri.
- Groq не поддерживает потоковое распознавание: текст появляется после конца записи, а не по словам во время речи. Псевдо-стриминг по VAD — этап 7.
- Минимум 10 секунд тарификации за запрос у Groq: очень короткие фразы невыгодны.
- Free tier Groq: 20 запросов/мин, 7 200 аудиосекунд/час, 28 800/день — на организацию, не на пользователя. Поэтому ключ живёт на сервере и не предназначен для публичного многопользовательского деплоя.
